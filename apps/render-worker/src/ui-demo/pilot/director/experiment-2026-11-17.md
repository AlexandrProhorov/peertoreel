# Эксперимент: разнообразие директора, 3 прогона × 5 тем

**Дата:** 2026-11-17 · **Модель:** DeepSeek, `temperature 0.8`, до 3 попыток
**Вход:** только тема + контракт из `catalog.ts`. Ни концепта, ни подсказок о структуре.
**Выход:** `out/exp/r1…r3/<тема>/episode.json`, видео — `out/exp/videos/rX-<тема>.mp4`.

## Принятие и стоимость

15 из 15 сцен прошли валидатор. Попыток на тему: 1–3 (чаще 1–2). Всего **$0.0208**.

## Техническое качество

| Метрика | Значение |
| --- | --- |
| Прошли DOM-линтер | **9 из 15 (60 %)** |
| `critical-in-platform-zone` (текст в правом рейле) | 4 |
| `text-overflow` (текст выше своего бокса) | 3 |
| `critical-outside-content` | 1 |

Ошибки повторяются у одной и той же темы (04 «функции» — 3/3 прогонов с ошибкой), а не
размазаны случайно. Это уже сигнал: тема требует плотной раскладки, а модель не умеет
считать бюджет места.

## Разнообразие

| Метрика | Значение |
| --- | --- |
| Уникальные наборы примитивов | **14 из 15** |
| Уникальные сигнатуры (примитивы + грубая раскладка 3×3) | **15 из 15** |
| Разных структур на одну тему за 3 прогона | 3, 3, 3, 2, 3 |

Вывод: разнообразие — свойство модели, а не удача одного сэмпла. Повторные прогоны на той же
теме дают другие структуры.

## Чего разнообразие не покрывает

**Пространство однообразное.** Если разложить центры элементов по трети кадра:

- левая треть (c0): **14 из 15** сцен целиком;
- правая треть (c2): встречается в **1** сцене из 15;
- нижняя треть (r2): **2** сцены, и только краем.

То есть модель придумывает разные наборы объектов, но ставит их всегда слева и сверху.
Отсюда впечатление «пустые ролики»: правая и нижняя половины кадра почти всегда пустые.

**Занятость по боксам:** 9.6 %–59.5 %, медиана ~31 %. Метрика слабая (пустая карточка даёт
площадь), но и она показывает разброс, а не норму.

**Заглушки:** в этой партии не найдено ни одной. Детектор узкий: «отзывы» и «рейтинг» как
содержимое он пропускает, а это ровно тот случай, когда смысла нет.

## Что это значит для следующего шага

1. Разнообразие доказано на N=15. Дальше его не надо «развивать» — надо чинить исполнение.
2. Главная техническая проблема — **бюджет места на кадр**: модель не знает, сколько
   занимает текст при выбранном токене. Пока это лечится только постфактум линтером.
3. Главная визуальная проблема — **систематический перекос влево-вверх**. Это не вкус,
   это измеримое свойство, и его видно на всех 15.
4. Смысл по-прежнему не измеряется. Для него нужен либо мультимодальный судья, либо
   рубрика с ручной разметкой.
