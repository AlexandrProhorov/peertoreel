## Что готово в пилоте

- 10 устройств, 11 примитивов (только токены), spec renderer, `CompositionSpec` + валидатор.
- DOM-линтер (реальный Chromium, safe zones, клиппинг, пересечения, шрифт, контракт).
- Quality-gate: стиль обязателен, иерархия, акцент, видимые поверхности, контраст.
- Семантика: реестр поведений с сигнатурой, evidence-цитаты, оси identity × executability,
  CLI `ui:fidelity`, независимый Judge (внешний harness).
- Детерминизм: кадры идентичны между процессами; mp4 — нет (энкодер). `--verify`, `--stills`.
- Паритет `prompt-card` на примитивах: mp4 побайтово идентичен.
