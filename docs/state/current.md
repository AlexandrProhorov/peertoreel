## Активная работа

Многосценный директор: `apps/render-worker/src/ui-demo/film/`. Тема → арка (3–5 сцен,
25–30 с) → сцены по отдельности → ремонт → проверка кадра → сборка → рендер.

Команда: `pnpm --filter @peertoreel/render-worker ui:film -- --input <topics.json> --out <dir>`
(`--no-action` — вариант без поля «визуальное действие»).

## Что готово

**Ролик.** `ui:film`: арка отдельным вызовом (замораживается), сцены генерируются против неё
независимо, повторяется только упавшая сцена. Тема кадра чередуется, длительность выводится
из шагов. Последний результат: 4 сцены, 29.7 с, $0.0072, 4 отклонённых JSON из 9 вызовов.

**Время.** Модель присылает упорядоченный список шагов без секунд; код раздаёт время по
таблице длительностей (`timing-plan.ts`), длительность сцены = max(задуманная, фактическая).
Обрубков больше нет по построению.

**Свойства примитивов.** Контракт в `catalog.ts` — единственный источник для промпта и
валидатора. `fontScale` ≥ 0.85, `typography-fit` (кегль по высоте бокса), `text-not-supported`
(текст только у текстовых примитивов), палитра проходит собственный контраст-гейт
(`themes.spec.ts`).

**Разметка.** Clamp в безопасную зону, `tokenForHeight` (кегль по боксу до валидации),
минимальный зазор 16 px для случайных наложений при сохранении коллажей (наложение >35 %
считается приёмом), плашки не режут паддинги.

**Анимации.** Один вход на элемент: либо блок, либо печать. Геометрия принадлежит своей
реплике (`fill`, `draw`, `break`, `drag`, `release`); без реплики — статичное конечное
состояние. `break` без реплики = целая шкала. `activate` не анимируется. `move`/`scale`
удалены как переходы — это были повторные входы в кадр.

## Измеренное (последние прогоны)

- 5 сцен × 3 прогона: 14 уникальных наборов примитивов из 15, 15 уникальных сигнатур.
- Шкала `track` — в 8 сценах из 16, в последнем фильме 3 из 4. Снятие требования «элементы
  двигаются» и поле «действие» частоту не изменили.
- Прохождение линтера по историческим прогонам: 13 из 25 (52 %) на смешанных версиях правил.
- Стоимость: $0.005–0.012 за фильм; отказы — по контракту, не по смыслу.

1. **Смысл не измеряется.** Гейты проверяют геометрию и контраст, не читаемость замысла.
   Мультимодального судьи нет — ключа под него в проекте нет.
2. **Первый кадр ролика серый** — артефакт раскраски страницы (кадр 1 уже нормальный).
3. **Словарь узкий:** 4 примитива из 9 имеют встроенную динамику, отсюда перекос в шкалы.
4. **Нет модели событий:** «кликнули → элемент дёрнулся» выразить нечем.
5. **Нет звука и субтитров** в UI-demo (путь в `apps/worker` не подключён).
