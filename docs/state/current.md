## Что готово

**Приёмка чужих ответов.** `ui:import <foreign.json> [episode.json]` читает ответ модели
(`{thesis, scenes[]}`), маппит в наш эпизод, гоняет ту же нормализацию и печатает статус каждой
сцены плюс каждый salvage; код выхода 1, если сцена потеряна. Ответы трёх моделей лежат
фикстурами: `apps/render-worker/fixtures/foreign/{gpt,claude,deepseek}-subscriptions.json`.

**Salvage вместо отказа.** `fit/salvage.ts` до валидации срезает неизвестные параметры,
`border: "none"` → отсутствие рамки, числа вне диапазона → ближайшая граница, `shadow: true/false`
→ `soft/none`, переходы вне контракта (например `grab`). Каждая правка пишется в отчёт
(`Repair`) и печатается в `ui:import`, `film/cli.ts`, `director/cli.ts`. Геометрию salvage не
трогает: элемент вне кадра после clamp — по-прежнему отказ.

**Координаты линии.** `line` рисуется в абсолютных координатах кадра (`devices/line-geometry.ts`),
`layout` остаётся рамкой. `spec-episode.json` переведён на ту же конвенцию; конвенция названа в
промпте.

**Один словарь текста.** `tone` у `label`, `pill`, `bubble`; `textColor` — у всех трёх; явный
цвет выигрывает у тона. Текстовый примитив больше не отказывает из-за имени параметра.

**Гейт поверхности** сравнивает поверхность с фоном объявленного `stage`, а не с фоном темы.

**`grab` убран** из контракта `thumb`; жест показывается `drag`, промпт генерируется из каталога.

## Открытые проблемы

1. **Смысл не измеряется.** Гейты проверяют геометрию и контраст, не читаемость замысла.
2. **Пустые блоки.** DeepSeek регулярно ставит поверхность без текста и роли; для гейта это
   легальная карточка. Кандидат в правило: поверхность без содержания не принимается.
3. **Первый кадр ролика серый** — артефакт раскраски страницы (кадр 1 уже нормальный).
4. **Словарь узкий:** 4 примитива из 9 имеют встроенную динамику, отсюда перекос в шкалы.
5. **Нет модели событий:** «кликнули → элемент дёрнулся» выразить нечем.
6. **Нет звука и субтитров** в UI-demo (путь в `apps/worker` не подключён).
