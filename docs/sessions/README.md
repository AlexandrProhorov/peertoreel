# Session records

`SESSION_LOG.md` — короткий индекс. Полные записи лежат здесь, по одной на сессию.

## Layout

```text
docs/sessions/<YYYY-MM>/<YYYY-MM-DD>-<NN>-<slug>.md
```

`NN` — порядковый номер сессии в этот день. `slug` — транслит названия.

## Новая запись

1. Скопируй `docs/templates/session-record.md`.
2. Заполни максимум 50 строк: цель, результат, файлы, решения, отклонения,
   что не проверено, блокеры, следующий шаг.
3. Добавь одну строку в таблицу `SESSION_LOG.md`.
4. Theory-блок (5–10 тезисов) пиши в локальный `LEARNING.md`, не сюда.

## Почему так

Старт сессии читает только индекс. Запись открывается по конкретной ссылке,
когда она действительно нужна, а не вся история сразу.
