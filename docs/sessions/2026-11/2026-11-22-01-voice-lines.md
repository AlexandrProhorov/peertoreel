## Цель

Сделать Google-озвучку источником темпа и текста в кадре: ролик 55–70 с, на экране —
главный тезис реплики, тезис появляется вместе со своими словами, субтитров нет.

## Результат

- Замер Google: 119 слов / 68.81 с сырого аудио = 1.73 слова/с; после обрезки тишины
  63.94 с = 1.86. Тишина вокруг ответа: 0.085–0.127 с в начале, 0.233–0.884 с в конце.
- `ui:voice` режет нарацию на строки (≤80 символов), синтезирует каждую отдельно,
  обрезает тишину, собирает сцену через `adelay`; старты строк точные по построению.
  На `film-minute2`: **71.61 → 65.60 с**.
- Модель cue: строки в `manifest.scenes[].lines` и в `scene.narrationLines`; слова
  остаются в `speech` для будущей подсветки. Длительности строк квантуются до 20 мс,
  повторный `ui:voice` даёт идентичный манифест.
- `ui:mux`: аудио по кадрам (`frameStart / fps`), `apad` больше не теряет хвост сцены.
- Экранный текст — тезис реплики в элементах сцены. Приёмка требует, чтобы каждая
  строка имела на экране короткий **дословный** фрагмент (2–6 слов), по порядку;
  служебные подписи до 3 слов и числа допустимы, длинный выдуманный текст — нет.
  `alignSceneToLines` ставит тезис на старт его первого слова внутри строки.
- Промпт: «на экране — главный тезис, а не вся речь»; тезис — крупный текст, не мелкая
  подпись; субтитров и отдельной полосы нет.
- Темп: норма в арке 2.2 → **1.7 слова/с**; план минуты — 10–12 сцен по ~5.5 с.
- Длительность сцены: план больше не режется на 10 % и не ограничивается `floor + 1`;
  действие растягивается через `stretchTiming` (раньше функция не использовалась).
- Переполнение карточки: карточка с собственным текстом маркируется `data-ui-overflow`
  и меряется целиком; `ui:fit` растит бокс и при необходимости уменьшает кегль.
- Подсветка тезиса (`mark`) переносится: `box-decoration-break: clone`, у каждой строки
  свой скруглённый фон.
- Гейт «примитивы не пересекают тезис»: `data-ui-thesis` на элементе тезиса, линии
  передаются правилам сегментом, поверхности — с порядком отрисовки. Карточка под
  текстом — фон, карточка поверх — ошибка `text-crossed`. Служебные подписи не
  защищаются.
- Фолбэк получает первое 5-слово реплики как тезис, поэтому даже деградированная
  сцена читается; озвучка допускает частичное совпадение для фолбэка.
- Нарация больше не описывает кадр: схема арки отклоняет «надпись», «на экране»,
  «карточка», «плашка», «тает», «эта линия» и подобное; в промпте есть пример
  «Надпись 0% тает» → «Обещание 0% исчезает, а переплата остаётся».

## Решения

- На экране — тезис реплики, а не вся строка; тезис должен быть дословным фрагментом.
- Синхронизация: старт строки точный; тезис — по словам, оценка Google.
- Модель cue провайдер-агностичная; ElevenLabs подключается только точностью `words[]`.
- Плановые секунды арки — контракт длительности; растягиваем действие.

## Не проверено / известные дефекты

- Точность старта тезиса внутри строки: Google не даёт выравнивания, проверки по звуку нет.
- Полный просмотр `final2.mp4` на слух и по кадрам.
- Часть сцен остаётся текстовой без визуального действия.
- Служебные подписи до 3 слов могут формулировать второй тезис («Платить придётся больше»).
