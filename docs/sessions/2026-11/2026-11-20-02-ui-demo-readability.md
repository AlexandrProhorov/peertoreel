# 2026-11-20 — UI-demo: читаемость кадра под нагрузкой модели

**Статус:** DONE
**Ветка:** `feat/m3-animated-factory` · **План:** `docs/workspace/plans/2026-11-19-ui-demo-meaning.md`

## Цель

Довести ролики до состояния «не стыдно смотреть»: убрать наслоения, обрезанный текст,
пустые блоки и висящие сцены, не теряя смысл.

## Результат

- Текст рисуется последним; сетка, на которой стоит контент, удаляется как декорация.
- Паддинг карточки применяется к детям, включая трек (рельса укорачивается до внутренней ширины).
- Текст на плашках не перекрывается: для поверхностей с текстом порог коллажа не действует.
- Текст, не влезающий на минимальном кегле, отклоняется с сообщением «нужно N px, есть M px».
- Пустая поверхность отклоняется; исключения — вложенность и сравнение двух фигур разного размера.
- Короткое действие растягивается на плановую длительность.
- Арка: лимиты подняты под реальный вывод модели, ошибки печатаются, JSON читается терпимо.

## Решения

- Геометрию и декор правит код, смысл — нет: наслоение и паддинг лечатся, пустой блок отклоняется.
- Пустые фигуры допустимы только как сравнение (одна сторона равна, другая отличается ≥20 %).
- DeepSeek-фикстура теперь документирует границу: 2 сцены из 4 отклоняются правилом.
