# 2026-11-20 — Bench: сигнатура сцены и перепись архива

**Статус:** DONE

## Цель

Получить цифры приёмки по уже оплаченным архивам без LLM и без рендера: сигнатура
структуры сцены и перепись словаря — в этом порядке, чтобы первый baseline не
пришлось пересчитывать.

## Результат

- `signature.ts`: `sceneSignature(scene)` и `rawSceneSignature(raw)`. Строгий ключ собран из
  примитивов в порядке появления, отношений (внутри / пересечение / рядом) и
  различающейся пары одного примитива. Текста и model-выбранных id в ключе нет:
  id заменены порядковым номером. Грубый ключ (`coarse`) — только мультимножество
  примитивов: строгий почти не повторяется, поэтому однообразие типа ловит грубый.
- `ui:bench` (`src/ui-demo/bench/`): читает `out/`, считает потерянные сцены,
  degraded/fallback, перепись по **сырым** `scene-*-attempt-*.json`, примитивы на фильм,
  уникальность сигнатур. Пишет `aggregate.json`, `runs/<run>.json`, `table.md`.
- Две колонки разделены: `model.*` (выдумки модели) и `gate.*` (наши отказы).
  `n/a` ставится там, где поле не записано в архиве; ноли не подставляются.
- По 28 прогонам: 450 плановых сцен, 405 сделано, **52 потеряно**; 405 сцен, 400
  уникальных строгих сигнатур (0.988) и 384 уникальных набора примитивов (0.948);
  `vocab/film` 5.15.
- Грубый ключ discriminates: у 21e наборы повторяются в 25 % сцен, у 21d — в 16 %;
  в пяти прогонах доля 1.00. Это и есть сторож против «все сцены — label + track».
- Перепись (181): `invalid-range` 51, `element-budget` 40, `invalid-spec` 32,
  `transition-dropped` 16, `unknown-operation` 12, `primitive-budget` 11,
  `property-mixup` 9, `invalid-type` 6, `unknown-parameter` 3, `dangling-link` 1;
  **`unknown-primitive` — 0**.
- Гейты (998): `text-contrast` 418, `empty-surface` 312, `accent-required` 57,
  `surface-visible` 55, `typography-fit` 48, `hierarchy-required` 33,
  `surface-overlap` 31, `grid-overlap` 29, `style-required` 15.
- Потери сконцентрированы в ранних прогонах (20b, 20j, 20k — по 5–7); в n, o, p, q
  потерь нет, degraded есть только у n (1), o/p/q — 0.

## Решения

- Плановые сцены берутся из индексов `scene-<n>-attempt-*`, а не из арки: `arc.json` —
  это 20 бит, фильм берёт 4, поэтому «потеряно = 20 − 4» было ложью. `report.json`
  перекрывает индексы, когда он есть.
- Архив перепроверяется сегодняшним контрактом, а не контрактом своего дня: иначе
  прогоны несравнимы. Это записано в шапке отчёта.
- `degraded` есть только у n, o, p, q; у остальных `n/a`, а не 0 — иначе первая же
  серия «улучшится» сменой схемы отчёта.
- `fallback` пока `n/a`: архетип не реализован.

**Повторный прогон (2026-11-21).** Стенд запущен ещё раз на тех же архивах без изменений
контракта: `aggregate.json` совпал до числа — 28 прогонов, 450 плановых / 405 сделанных /
52 потерянных, 0.988 строгих и 0.948 грубых сигнатур, `vocab/film` 5.15. Требование шага 0
«цифры воспроизводятся на двух прогонах» закрыто; воспроизводимость держится на том, что
стенд не пишет время в агрегат и читает архивы, а не модель.

## Отклонения от плана

- `film-2026-11-21l`: нет ни отчёта, ни attempt-файлов → `planned` и `lost` = `n/a`.
- Отчёты лежат не только в корне прогона: часть — в `review/report.json`; читаются оба.
- Каталог `docs/workspace/` gitignored, поэтому `metrics.json` остаётся локальным.

## Не проверено

- Кадры не смотрели: срез не касается рендера.
- Точность сигнатуры как меры разнообразия на длинной серии (100 сцен) — впереди.

## Блокеры и следующий шаг

- `property-mixup` и `transition-dropped` в spec-эре подтверждают пункт про алиасы.
- `invalid-range` (51) и `element-budget` (40) — кандидаты на детерминированный ремонт,
  а не на ретрай.
- Следующий шаг: 7a — сцена не теряется никогда (лучшая попытка → легализатор →
  fallback-архетип), затем строгий словарь.
