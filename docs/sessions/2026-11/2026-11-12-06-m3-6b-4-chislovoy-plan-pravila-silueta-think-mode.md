## Цель

Вернуть стабильную сборку: PLAN как чертёж (координаты, слои, габарит), правила силуэта и
пропорций, think mode как рабочий режим.

## Результат

- Промпт: PLAN обязан перечислять каждый элемент с числами и палитру; указывается bbox объекта;
  голова/плод/солнце/мяч — `circle`/`ellipse` (не `rect`); животное — `ellipse`/капсулы;
  техника — скруглённые `rect`; детали внутри силуэта с отступом 8–16; окна/клавиши разделяются
  промежутком, а не второй заливкой; колесо — концентрические круги разных цветов, арка шире
  шины; 10–18 примитивов.
- `DeepSeekSvgProvider`: `thinking` по умолчанию `enabled`, `max_tokens` 16000 (рассуждение
  считается в тот же бюджет; 6000 давало пустой content). `thinking: disabled` остаётся
  опцией для дешёвых прогонов.
- A/B bus/palm/pirate (по 3 кандидата): **9/9 годных**, $0.071 за 9 вызовов, $0.003–0.006 за
  кандидата (пират — два attempt'а), 16–115 с. Thinking off: 9/9, $0.0056, ~4 с, но композиция
  «плывёт».
- Галерея: `apps/render-worker/out/m3-6b-5/pilot/gallery.html`.

## Изменённые файлы

## Решения

- Think mode — рабочий режим; цена ≈$0.003–0.008 за кандидата остаётся ниже Recraft ($0.05–0.08).
- `max_tokens` 16000, а не 6000: иначе reasoning выедает видимый вывод.
- Правила силуэта формулируются обобщённо (класс форм), без per-object кода.

## Не проверено

- Визуальная оценка bus/palm после правок — за человеком.
- Серия >10 объектов и консистентность между роликами.

## Блокеры и следующий шаг

- Если пальма/автобус всё ещё не устраивают — двухшаговый plan-first вызов (план отдельным
  дешёвым запросом, рендер без thinking) как способ снизить цену стабильного think mode.
- Затем коммит M3.6b.2–b.4.
