# 2026-11-21 — Минутный ролик с озвучкой и субтитрами

**Статус:** DONE (первый проход)
**Ветка:** `feat/ui-demo-bench-signature` · **План:** очередь v2, пункт 3

## Цель

Собрать ролик около минуты: длинная арка, озвучка по сценам, субтитры по фактической
речи, финальный mp4 с аудио.

## Результат

- Арка: `--seconds 60` → окно 55–65 с и 8–10 сцен; у каждой сцены появилось `narration`
  (речь голоса) с нормой ~2.2 слова в секунду.
- `ui:film --seconds 60`: 8/8 сцен, визуально 45.6 с, $0.0128.
- `ui:voice`: 8 сцен, **71.6 с речи** (Google TTS читает медленнее нормы), каждая сцена
  растянута до `аудио + 0.35 с`; `subtitles.srt` из пословных таймингов.
- `ui:demo` по озвученному эпизоду: 2148 кадров.
- `ui:mux`: аудио по смещениям сцен + прожиг субтитров → `final.mp4`, **71.3 с**,
  1080×1920, 30 fps, H.264 + AAC, 2.4 МБ.

Артефакт: `apps/render-worker/out/film-minute2/01-installments/final.mp4`.

## Что изменилось в коде

- `packages/providers`: ElevenLabs вынесен из воркера (адаптер провайдера, не приложения);
  добавлен бесплатный Google Translate TTS как явный fallback.
- `film/arc.ts`: `narration`, окно по запрошенной длине (`arcPlanFor`, `arcSchemaFor`),
  фраза о темпе речи.
- `film/voice.ts` (+ spec): слова из посимвольного выравнивания, оценка таймингов для
  провайдера без выравнивания, нарезка реплик, SRT.
- `film/voice-cli.ts`: TTS по сценам, пересчёт длительностей, `manifest.json` с
  `alignment: exact|estimated`.
- `film/mux.ts`: сборка аудио (adelay + amix), прожиг SRT с отступом от нижней панели.

## Решения

- Квота ElevenLabs — терминальная ошибка с подсказкой `--provider google`, без тихого
  фейловера; провайдер и тип таймингов пишутся в манифест.
- Сцена живёт не короче своей речи: картинка удлиняется, содержимое доигрывает и держится.
- Субтитры поднимаются над платформенной панелью (`MarginV=55` в единицах ASS ≈ 360 px),
  а не лежат под ней.

## Отклонения от плана

- Ролик 71.3 с, не 60: TTS читает ~1.8 слова/с вместо 2.2. Норма в промпте уточняется,
  либо длительность добирается числом сцен.
- Озвучка Google, не ElevenLabs: квота исчерпана (10 кредитов из 106 нужных).
- Пословные тайминги Google — оценочные (`estimated`), не по выравниванию.

## Не проверено

- Синхронность «слово ↔ реплика» на слух по всему ролику.
- Вид субтитров в реальном плеере TikTok (шрифт Onest в libass не подключён).

## Блокеры и следующий шаг

- ElevenLabs: нужна новая квота или ключ; до этого точные тайминги недоступны.
- Дальше: подогнать темп речи под 60 с, посмотреть ролик целиком, затем ASS-караоке.
