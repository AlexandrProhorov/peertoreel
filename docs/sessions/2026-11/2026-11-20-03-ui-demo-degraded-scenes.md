# 2026-11-20 — Сцена не теряется: degraded-сцены и длина из действий

**Статус:** DONE
**Ветка:** `feat/m3-animated-factory` · **План:** `docs/workspace/plans/2026-11-21-next-session.md`

## Цель

Сделать таймлайн и приёмку сцены отказоустойчивыми: ролик не должен терять сцены,
сцена не должна обрываться на последнем кадре анимации.

## Результат

- Длина сцены выводится из действий: `max(конец действия + hold, min(план × 0.9, ... + 1 с))`;
  hold 0.8 с после движения, 1.6 с после текста, пол 0.25 с.
- Сцена-обрыв (`03-discount`, 2.0 с при конце анимации 2.0 с) закреплена тестом.
- Degraded-сцены: после исчерпания попыток сохраняется последняя отремонтированная версия
  с плановой длительностью, `*` на кадре, `degraded.reasons` в эпизоде, `status: degraded`
  в отчёте.
- Fallback-сцена из `intent` арки, если валидной композиции не было ни в одной попытке.
- Инвариант полноты: неполный фильм не пишется, прогон завершается с кодом 1.
- Отказ `empty-surface` переформулирован: пустая фигура не показывает идею.

## Решения

- План модели — намерение, а не потолок; потолок ставит код.
- Компакция применяется только при выводе тайминга; повторная нормализация не сжимает сцену.
- Degraded-сцена держит плановые секунды: таймлайн делят озвучка и субтитры.
- Пустые фигуры остаются запрещёнными: генерация ассетов — будущая версия, сейчас это шум.
- Наслоение «СКИДКА» не чиним: это запрос на приём «раскол», перенесён в расширение библиотеки.
