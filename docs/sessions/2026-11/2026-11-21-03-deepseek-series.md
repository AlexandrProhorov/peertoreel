## Решения

- Лестница подтверждена: 0 потерянных сцен при 2 degraded. Цель по degraded — 3 % —
  остаётся KPI, но по одной серии её не назначать.
- Кадровые проверки не дали ни одного ложного срабатывания на 26 сценах; `text-overflow`
  согласуется со спек-проверкой переполнения.
- Тонкая сигнатура снова насыщена (1.00): сторожем разнообразия остаётся грубая.

## Отклонения от плана

- 8e (ручной GPT по `prompts.md`) не делался: нужен внешний прогон.
- Разметка 30–50 кадров не расширялась: хватило 26 сцен для первой проверки правил.

## Блокеры и следующий шаг

- Degraded 7.7 % → 3 %: две конкретные причины. (1) при удалении пустой поверхности
  сцена теряет главный токен — нужно либо повышать крупный текст до главного, либо
  не удалять единственную крупную фигуру без замены; (2) переполнение длинного слова
  в узком боксе — подсказка уже есть, нужен ремонт «вырасти бокс / сократи слово».
- Дальше: 8e (внешний GPT) или фикс двух причин degraded, затем повтор серии.
