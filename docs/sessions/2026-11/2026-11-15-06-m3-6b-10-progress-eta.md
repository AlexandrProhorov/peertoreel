# 2026-11-15 — M3.6b.10: честный прогресс рендера и state guard

**Статус:** DONE · **Ветка:** `feat/m3-animated-factory`
**План:** нет отдельной карточки; шаг 1 из договорённости по надёжности
Цель

Убрать ощущение «зависшего экрана» на длинных стадиях и закрыть известную дыру в проверке
состояния script-стадии.
Результат

- `stageJobProgressSchema` и `stageJobUnitSchema` в contracts: `percent`, `phase`,
  `unit { label, index, total }`, `elapsedMs`, `estimatedRemainingMs`.
- `StageJobSnapshot.progressDetail` — опциональное объяснение прогресса; старый `progress`
  остался числом, обратная совместимость сохранена.
- Renderer CLI печатает машинные строки `##progress {...}`: `total` перед рендером сцен и
  `scene` после каждой сцены (`index`, `total`, `id`, `renderMs`). Человеческие логи не тронуты.
- Worker `render-cli` читает stdout построчно, парсит только префикс, отдаёт события через
  `onProgress`; битые строки игнорируются.
- `episode_render` обновляет BullMQ прогресс объектом: процент 15–70 по сценам, `unit`,
  `elapsedMs`, ETA по среднему времени завершённых сцен.
- API `stages.queue` разбирает объектный прогресс через схему и отдаёт `progressDetail`;
  неизвестные формы не ломают снапшот.
- Web: в мета-строке прогресса «Сцена 2 из 5» и «~12 с», aria-label включает номер сцены.
- `processScriptStage`: проверка `STAGE_REQUIRED_STATE.script` перед работой; идемпотентный
  ранний выход для `SCRIPT_READY` сохранён.
- Проверка: `render-storyboard --scene 0` печатает `total`/`scene` события; `pnpm check` зелёный.

Решения

- Машинный прогресс — отдельный префикс в stdout, а не изменение формата логов: рендерер
  остаётся CLI, worker не импортирует Remotion.
- ETA считается по уже отрендеренным сценам; до первой сцены — `null`, а не выдуманное число.
- Числовой `progress` не заменяется объектом: старые клиенты и тесты продолжают работать.
Не проверено

- Реальный прогон стадии через очередь и UI (нужны Redis, worker и браузер) — `Not verified`.
- Формат строки `##progress` может измениться: парсер терпим к мусору, но это внутренний контракт.
